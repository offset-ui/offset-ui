# Security policy

## Supported versions

Only the latest release of Offset UI receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub: <https://github.com/offset-ui/offset-ui/security/advisories/new>. Include what you found, how to reproduce it, and which component or page is affected.

We aim to reply within 7 days, and to publish a fix and a note in the changelog once the problem is resolved.

## Scope

Offset UI is copy-and-paste front-end code and a docs site. Reports about the components, the docs site, or the build and CI setup are all welcome.
