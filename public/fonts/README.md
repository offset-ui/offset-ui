# Fonts

Latin-only WOFF2 subsets (Basic Latin, Latin-1, common punctuation) of the fonts used in the Figma design:

| File | Font | Used for |
| --- | --- | --- |
| `SFCompactText-Regular.woff2` | SF Compact Text Regular | Home hero headline |
| `SFCompactText-HeavyItalic.woff2` | SF Compact Text Heavy Italic | "touch twice" |
| `Futura-Bold-Italic.woff2` | Futura Bold Italic | "Offset MOTION" |

These are third-party typefaces (SF Compact © Apple Inc.; Futura is a commercial typeface). They are included here
because the project owner chose to ship the Figma design as-is. Check that your licence covers web use and public
redistribution before you fork or reuse them, and swap them for a licensed alternative if it does not. The `@font-face`
rules are in `app/globals.css`.
